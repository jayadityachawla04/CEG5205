# Anatomical torso and organs

Source: [Innerscene, Torso with removable organs](https://www.innerscene.com/tools/library/3d-parts/torso-with-removable-organs-1fe1b70a), downloaded 2026-10-26.

License: CC0 1.0. The source page identifies the asset as an Innerscene model adapted from MakeHuman CC0 assets. This project uses separate organ meshes and downsampled textures from the GLB. The existing full-body MakeHuman patient mesh remains the visible exterior.

`torso-with-removable-organs.glb` is the unmodified source. `Prepared/` contains axis-converted mesh data generated by `Tools/prepare_anatomy.py`; Unity imports it into native Mesh assets. These are educational visual models, not clinical anatomy.

The separate graspable hearts use [Innerscene, Heart with major blood vessels](https://www.innerscene.com/tools/library/3d-parts/heart-with-major-blood-vessels-2b67da90), also CC0. `heart-with-major-blood-vessels.glb` is its unmodified source; `HeartPrepared/` and `Assets/Surgery/Models/HeartTextures/` are generated by `Tools/prepare_heart.py`. This model is also an educational visual asset, not validated surgical anatomy.
