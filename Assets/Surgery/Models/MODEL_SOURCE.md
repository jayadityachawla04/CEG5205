# Practice patient body mesh

`PracticePatientBody.obj` contains only the `body` surface extracted from MakeHuman's `makehuman/data/3dobjs/base.obj`. The unused helper and joint marker groups were removed for Quest performance. The mesh is placed supine, with a sterile drape and a simulated training field.

Source: https://github.com/makehumancommunity/makehuman/blob/master/makehuman/data/3dobjs/base.obj

License: CC0 1.0 Universal, as stated in the source OBJ and MakeHuman's `LICENSE.md`. The full CC0 terms are in `LICENSE.ASSETS.md`.

This is a generic synthetic human mesh used as a practice cadaver. It is not a clinically validated anatomical model.

`PracticePatientSkin.png` is the MakeHuman system asset `young_lightskinned_male_diffuse.png`, from the official [MakeHuman skin asset directory](http://free.downloads.tuxfamily.net/makehuman/assets/1.1/base/skins/textures/). It uses the base mesh UV layout and is CC0, as documented by the MakeHuman asset catalog and license. The source image includes a printed CC0 mark.
