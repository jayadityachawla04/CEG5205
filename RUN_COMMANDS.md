# CEG 5205 — Run commands

**Note:** Open the extracted Unity project folder (the one containing `Start-ROS.ps1`) in File Explorer. Click the address bar, type `powershell`, and press Enter. Run these commands there, not in Unity Console. If the PowerShell prompt shows `C:\Windows\system32>`, you are in the wrong folder.

## Part 2

```powershell
powershell -ExecutionPolicy Bypass -File .\Start-ROS.ps1 -Part 2
```
